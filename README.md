# Danuri · Korean, together

[Open the public learning app](https://happybin72.github.io/danuri-korean/). No account required. Mobile-friendly static PWA with an EN / 日本語 switch and device-specific home screen installation guide. Japanese definitions are matched to the same NIKL dictionary entry and sense; Korean lesson text and progress IDs are preserved.

11,076 NIKL-sourced vocabulary entries across six learning levels, 3,966 expression headwords and 985 grammar patterns, plus original supplementary cards and 40 mini mock questions. Learning levels are not official TOPIK word assignments. No verified past-exam occurrence is claimed. See [data attribution](data/ATTRIBUTION.md).

Progress, notes and personal cards stay in the visitor's browser. Settings provides backup import/export. Optional GA4 loads after consent; personal learning text is excluded from event parameters.

GitHub Pages publishes main at the repository root. Files use relative URLs and support this project path. Serve the directory with any static HTTP server for local development.
